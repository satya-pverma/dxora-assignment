# Live evidence

[Four-platform publishing response](posting-live-2026-11-18.json) was supplied by
the developer from the local application on 18 November 2026. It is a live result,
not a synthetic test fixture. Date/time fields are UTC. The exact request body
and endpoint were not included with this JSON and are not reconstructed here.

All four platforms confirmed publication. Bluesky and Telegram passed automatic
anonymous visibility verification. Mastodon and Tumblr retained confirmed post
URLs but their visibility checks were inconclusive; false does not establish
that a post is private. These links have not been independently rechecked as part
of saving this evidence. No message was republished.

WordPress, the fifth required destination, remains unverified. This response is
not evidence of a deployed application or a five-platform demonstration.
Secrets and authorization headers are not included.
